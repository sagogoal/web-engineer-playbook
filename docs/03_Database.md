# 03. データベース

---
## 3.1. データモデリング
- [ ] **DB-001:** サロゲートキーとナチュラルキーの違いを説明できる。
- [ ] **DB-002:** 複合主キーが必要になるケースを説明できる。
- [ ] **DB-003:** UUID（v4）を主キーにするメリット・デメリットを説明できる。
- [ ] **DB-004:** 外部キーの参照整合性アクション（CASCADE, RESTRICT, SET NULL）を説明できる。
- [ ] **DB-005:** 多対多リレーションを表現するための中間テーブルを設計する。
  <details>
  <summary>手を動かす</summary>
  - 「記事（posts）」と「タグ（tags）」の多対多関係を表現する中間テーブル`post_tags`のCREATE TABLE文を記述する。
  </details>
- [ ] **DB-006:** 第3正規形までの正規化を説明できる。
- [ ] **DB-007:** 住所録テーブルを例に、第1正規形に正規化する。
- [ ] **DB-008:** 注文テーブルを例に、第2正規形に正規化する。
- [ ] **DB-009:** パフォーマンスのために非正規化を検討するケースを説明できる。
- [ ] **DB-010:** 文字列型（VARCHAR, CHAR, TEXT）の使い分けを説明できる。
- [ ] **DB-011:** 数値型（INT, BIGINT, DECIMAL）の使い分けを説明できる。
- [ ] **DB-012:** 日付・時刻型（DATE, DATETIME, TIMESTAMP）のタイムゾーンの扱いの違いを説明できる。
- [ ] **DB-013:** NOT NULL, UNIQUE, CHECK制約を使い分ける。
- [ ] **DB-014:** 論理削除と物理削除のメリット・デメリットを説明できる。
- [ ] **DB-015:** JSON型の使い所と注意点（インデックス、検索性）を説明できる。
- [ ] **DB-016:** ENUM型のメリット（データ整合性）とデメリット（変更コスト）を説明できる。
- [ ] **DB-017:** ポリモーフィック関連（例: `commentable_type`, `commentable_id`）の設計パターンと注意点を説明できる。
- [ ] **DB-018:** 単一テーブル継承（STI）の設計パターンと注意点を説明できる。

## 3.2. SQL実践
- [ ] **DB-019:** `INNER JOIN`と`LEFT JOIN`の違いをSQLで記述して示す。
  <details>
  <summary>手を動かす</summary>
  - `users`テーブル（user A, B）と`posts`テーブル（user Aの投稿のみ）を準備し、両方のJOIN結果がどう変わるかを示すSQLと結果を記述する。
  </details>
- [ ] **DB-020:** 3つ以上のテーブルをJOINするSQLを書ける。
- [ ] **DB-021:** `GROUP BY`と集計関数（`COUNT`, `SUM`, `AVG`）を使い、ユーザーごとの投稿数や平均スコアなどを集計するSQLを書ける。
- [ ] **DB-022:** `WHERE`と`HAVING`の違いを説明できる。
- [ ] **DB-023:** 相関サブクエリと非相関サブクエリの違いを説明できる。
- [ ] **DB-024:** `EXISTS`句を使ったSQLを書ける。
- [ ] **DB-025:** ウィンドウ関数（`ROW_NUMBER`, `RANK`）の使い分けを説明できる。
- [ ] **DB-026:** ウィンドウ関数を使い、カテゴリごとの価格が高い順ランキングを取得するSQLを書ける。
- [ ] **DB-027:** `CASE`式を使って、条件に応じて表示する値を変えるSQLを書ける。
- [ ] **DB-028:** `UNION`と`UNION ALL`の違いを説明できる。
- [ ] **DB-029:** N+1問題を検知し、`IN`句を使って解決するSQLを書ける。
- [ ] **DB-030:** `INSERT`, `UPDATE`, `DELETE`文をそれぞれ書ける。
- [ ] **DB-031:** CTE (共通テーブル式) を使って、複雑なクエリを読みやすく書ける。
- [ ] **DB-032:** 再帰CTEを使い、階層構造（組織図など）を取得するSQLを書ける。
- [ ] **DB-033:** `UPSERT`（`INSERT ON CONFLICT` や `ON DUPLICATE KEY UPDATE`）を実装する。
- [ ] **DB-034:** `COALESCE` や `NULLIF` を使って、NULL値を扱うSQLを書ける。

## 3.3. パフォーマンス
- [ ] **DB-035:** インデックスが使われる仕組みをB-Tree構造を元に説明できる。
- [ ] **DB-036:** `EXPLAIN`（や`EXPLAIN ANALYZE`）を使い、SQLの実行計画を読んでフルスキャンやインデックス利用状況を確認できる。
- [ ] **DB-037:** 複合インデックスにおいて、カラムの順番が重要な理由を説明できる。
- [ ] **DB-038:** カバリングインデックスのメリットを説明できる。
- [ ] **DB-039:** インデックスが効かない`WHERE`句の書き方（`LIKE`の中間一致、カラムに関数を適用するなど）を説明できる。
- [ ] **DB-040:** `ANALYZE` の役割と、PostgreSQLの自動ANALYZEデーモンの挙動を説明できる。
- [ ] **DB-041:** オフセットページネーションの問題点と、カーソルページネーションでの解決策を説明できる。
- [ ] **DB-042:** スロークエリログを有効化し、`log_min_duration_statement` の設定方法を学ぶ。
- [ ] **DB-043:** 部分インデックス（Partial Index）のユースケースを説明できる。
- [ ] **DB-044:** 式インデックス（Expression Index）のユースケースを説明できる。
- [ ] **DB-045:** GINインデックスやGiSTインデックスなど、特殊なインデックスの種類を2つ以上挙げられる（PostgreSQL）。
- [ ] **DB-046:** マテリアライズドビューのユースケースと更新方法を説明できる。

## 3.4. トランザクションとロック

- [ ] **DB-049:** `BEGIN`, `COMMIT`, `ROLLBACK`を使い、簡単なトランザクション処理をSQLで記述できる。
- [ ] **DB-050:** トランザクション分離レベルの違い（`READ UNCOMMITTED`から`SERIALIZABLE`まで）を説明できる。
- [ ] **DB-051:** ダーティリード、ファジーリード（非再現読み取り）、ファントムリードの違いを説明できる。
- [ ] **DB-052:** 共有ロックと排他ロックの違いを説明できる。
- [ ] **DB-053:** `SELECT ... FOR UPDATE`を使い、行レベルで排他ロックをかけるSQLを書ける。

- [ ] **DB-055:** ライブロックについて説明できる。
- [ ] **DB-056:** MVCC（多版型同時実行制御）の基本的な仕組みを説明できる。
- [ ] **DB-057:** 悲観的ロックと楽観的ロックの使い分けを、具体的なシナリオを挙げて説明できる。

## 3.5. PostgreSQL 運用と管理
- [ ] **DB-060:** PostgreSQLの主要なプロセスアーキテクチャ（Postmaster, Backend, WAL Writerなど）を説明できる。
- [ ] **DB-061:** `postgresql.conf` と `pg_hba.conf` の役割の違いを説明できる。
- [ ] **DB-062:** `shared_buffers` や `work_mem` といった主要なメモリ関連パラメータの役割を説明できる。
- [ ] **DB-063:** DBマイグレーションツールの役割を説明できる。
- [ ] **DB-064:** オンラインスキーマ変更ツール（`pt-online-schema-change`, `gh-ost`など）の必要性を説明できる。
- [ ] **DB-065:** コネクションプーリングの仕組みとメリットを説明できる。
- [ ] **DB-066:** コネクションプーラー（PgBouncerなど）の役割と設定方法を学ぶ。
- [ ] **DB-067:** WAL（Write-Ahead Logging）の役割と、アーカイブログの仕組みを説明できる。
- [ ] **DB-068:** `pg_dump`と`pg_dumpall`を使った論理バックアップの取得方法を学ぶ。
- [ ] **DB-069:** `pg_basebackup`を使った物理バックアップの取得方法を学ぶ。
- [ ] **DB-070:** ポイントインタイムリカバリ（PITR）の概要と手順を説明できる。
- [ ] **DB-071:** `VACUUM`, `VACUUM FULL`, `autovacuum` の違いと役割を説明できる（PostgreSQL）。
- [ ] **DB-072:** テーブルやインデックスのBloat（肥大化）の原因と、その監視・解消方法を説明できる。
- [ ] **DB-073:** DBのバージョンアップ計画（マイナー/メジャー）と、`pg_upgrade` の役割を説明できる。
- [ ] **DB-074:** テーブルスペースの役割と、データファイルの配置場所を管理する方法を学ぶ。
- [ ] **DB-075:** よく使うpsqlのメタコマンド（`\d`, `\dt`, `\l`, `\c`, `\timing`など）を5つ以上使える。
