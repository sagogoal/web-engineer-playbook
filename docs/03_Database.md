# 03. データベース

---
## 3.1. データモデリング
- [ ] **DB-001:** サロゲートキーとナチュラルキーの違いを説明できる。
- [ ] **DB-002:** 複合主キーが必要になるケースを説明できる。
- [ ] **DB-003:** UUID（v4）を主キーにするメリット・デメリットを説明できる。
- [ ] **DB-004:** 外部キーの参照整合性アクション（CASCADE, RESTRICT, SET NULL）を説明できる。
- [ ] **DB-005:** 多対多リレーションを表現するための中間テーブルを設計する。
  <details>
  <summary>手を動かす</summary>
  - 「記事（posts）」と「タグ（tags）」の多対多関係を表現する中間テーブル`post_tags`のCREATE TABLE文を記述する。
  </details>
- [ ] **DB-006:** 第3正規形までの正規化を説明できる。
- [ ] **DB-007:** 住所録テーブルを例に、第1正規形に正規化する。
- [ ] **DB-008:** 注文テーブルを例に、第2正規形に正規化する。
- [ ] **DB-009:** パフォーマンスのために非正規化を検討するケースを説明できる。
- [ ] **DB-010:** 文字列型（VARCHAR, CHAR, TEXT）の使い分けを説明できる。
- [ ] **DB-011:** 数値型（INT, BIGINT, DECIMAL）の使い分けを説明できる。
- [ ] **DB-012:** 日付・時刻型（DATE, DATETIME, TIMESTAMP）のタイムゾーンの扱いの違いを説明できる。
- [ ] **DB-013:** NOT NULL, UNIQUE, CHECK制約を使い分ける。
- [ ] **DB-014:** 論理削除と物理削除のメリット・デメリットを説明できる。

---
## 3.2. SQL実践
- [ ] **DB-015:** `INNER JOIN`と`LEFT JOIN`の違いをSQLで記述して示す。
  <details>
  <summary>手を動かす</summary>
  - `users`テーブル（user A, B）と`posts`テーブル（user Aの投稿のみ）を準備し、両方のJOIN結果がどう変わるかを示すSQLと結果を記述する。
  </details>
- [ ] **DB-016:** 3つ以上のテーブルをJOINするSQLを書ける。
- [ ] **DB-017:** `GROUP BY`と`COUNT`を使い、ユーザーごとの投稿数を集計するSQLを書ける。
- [ ] **DB-018:** `WHERE`と`HAVING`の違いを説明できる。
- [ ] **DB-019:** 相関サブクエリと非相関サブクエリの違いを説明できる。
- [ ] **DB-020:** `EXISTS`句を使ったSQLを書ける。
- [ ] **DB-021:** ウィンドウ関数（`ROW_NUMBER`, `RANK`）の使い分けを説明できる。
- [ ] **DB-022:** ウィンドウ関数を使い、カテゴリごとの価格が高い順ランキングを取得するSQLを書ける。
- [ ] **DB-023:** `CASE`式を使って、条件に応じて表示する値を変えるSQLを書ける。
- [ ] **DB-024:** `UNION`と`UNION ALL`の違いを説明できる。
- [ ] **DB-025:** N+1問題を検知し、`IN`句を使って解決するSQLを書ける。
- [ ] **DB-026:** `INSERT`, `UPDATE`, `DELETE`文をそれぞれ書ける。

## 3.3. パフォーマンス
- [ ] **DB-027:** インデックスが使われる仕組みをB-Tree構造を元に説明できる。
- [ ] **DB-028:** `EXPLAIN`を使い、SQLの実行計画からフルスキャンが発生していることを確認できる。
- [ ] **DB-029:** 複合インデックスにおいて、カラムの順番が重要な理由を説明できる。
- [ ] **DB-030:** カバリングインデックスのメリットを説明できる。
- [ ] **DB-031:** インデックスが効かない`WHERE`句の書き方（`LIKE`の中間一致など）を説明できる。
- [ ] **DB-032:** `ANALYZE TABLE`の役割を説明できる。
- [ ] **DB-033:** オフセットページネーションの問題点と、カーソルページネーションでの解決策を説明できる。
- [ ] **DB-034:** スロークエリログを有効化し、実行に時間がかかったクエリを特定する方法を学ぶ。

## 3.4. トランザクションとロック
- [ ] **DB-035:** ACID特性（原子性, 一貫性, 独立性, 永続性）をそれぞれ説明できる。
- [ ] **DB-036:** `BEGIN`, `COMMIT`, `ROLLBACK`を使い、簡単なトランザクション処理をSQLで記述できる。
- [ ] **DB-037:** トランザクション分離レベルの違い（`READ COMMITTED`, `REPEATABLE READ`）を説明できる。
- [ ] **DB-038:** ダーティリード、ファジーリード、ファントムリードの違いを説明できる。
- [ ] **DB-039:** 共有ロックと排他ロックの違いを説明できる。
- [ ] **DB-040:** `SELECT ... FOR UPDATE`を使い、行レベルで排他ロックをかけるSQLを書ける。
- [ ] **DB-041:** デッドロックがどのような状況で発生するかを説明できる。
- [ ] **DB-042:** ライブロックについて説明できる。
