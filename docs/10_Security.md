# 10. セキュリティ

---
## 10.1. Webアプリケーションの脆弱性
- [ ] **SEC-001:** XSS（クロスサイトスクリプティング）の脆弱性の原理と対策（エスケープ処理）を説明できる。
- [ ] **SEC-002:** ユーザーの入力値を画面に表示する際に、意図的にエスケープを無効化してXSSを発生させてみる。
- [ ] **SEC-003:** CSRF（クロスサイトリクエストフォージェリ）の脆弱性の原理と対策（CSRFトークン）を説明できる。
- [ ] **SEC-004:** SQLインジェクションの脆弱性の原理と対策（プレースホルダ）を説明できる。
- [ ] **SEC-005:** OSコマンドインジェクションの脆弱性の原理を説明できる。
- [ ] **SEC-006:** ディレクトリトラバーサルの脆弱性の原理を説明できる。
- [ ] **SEC-007:** SSRF（サーバーサイドリクエストフォージェリ）の脆弱性の原理を説明できる。
- [ ] **SEC-008:** オープンリダイレクトの脆弱性の原理を説明できる。
- [ ] **SEC-009:** クリックジャッキングの脆弱性の原理と対策（`X-Frame-Options`ヘッダー）を説明できる。
- [ ] **SEC-010:** 安全でないデシリアライゼーションの脆弱性を説明できる。
- [ ] **SEC-011:** XXE（XML外部実体参照）攻撃の脆弱性を説明できる。
- [ ] **SEC-012:** OWASP Top 10の最新版の項目を3つ以上挙げられる。
- [ ] **SEC-013:** 脆弱性診断ツール（OWASP ZAPなど）を使い、ローカルのアプリケーションをスキャンしてみる。

---
## 10.2. 認証とセッション管理
- [ ] **SEC-014:** Cookieとセッションの仕組みを説明できる。
- [ ] **SEC-015:** Cookieの属性（`Secure`, `HttpOnly`, `SameSite`）の役割を説明できる。
- [ ] **SEC-016:** `SameSite`属性の`Strict`, `Lax`, `None`の違いを説明できる。
- [ ] **SEC-017:** セッション固定化（Session Fixation）攻撃の原理と対策を説明できる。
- [ ] **SEC-018:** パスワードのハッシュ化とソルトの重要性を説明できる。
- [ ] **SEC-019:** 多要素認証（MFA）の必要性を説明できる。
- [ ] **SEC-020:** TOTP（時間ベースのワンタイムパスワード）の仕組みを説明できる。

---
## 10.3. Webサーバー・ネットワーク
- [ ] **SEC-021:** HTTPS（SSL/TLS）が提供する価値（暗号化、改ざん検知、認証）を説明できる。
- [ ] **SEC-022:** HTTP Strict Transport Security (HSTS) ヘッダーの役割を説明できる。
- [ ] **SEC-023:** Content Security Policy (CSP) ヘッダーの役割を説明できる。
- [ ] **SEC-024:** CORS（オリジン間リソース共有）の仕組みをセキュリティの観点から説明できる。
- [ ] **SEC-025:** DoS/DDoS攻撃の概要を説明できる。
- [ ] **SEC-026:** WAF（Web Application Firewall）の役割を説明できる。
- [ ] **SEC-027:** ポートスキャンの概要を説明できる。

---
## 10.4. セキュアコーディング・その他
- [ ] **SEC-028:** 最小権限の原則を説明できる。
- [ ] **SEC-029:** フェイルセーフとフールプルーフの考え方を説明できる。
- [ ] **SEC-030:** ゼロトラストネットワークの考え方を説明できる。
- [ ] **SEC-031:** サプライチェーン攻撃の概要を説明できる。
- [ ] **SEC-032:** `npm audit`や`dependabot`を使い、依存ライブラリの脆弱性をチェックする。
- [ ] **SEC-033:** シークレット（APIキーなど）をGitリポジトリにコミットしてはいけない理由を説明できる。
- [ ] **SEC-034:** Git-secretsなどのツールを使い、誤ってシークレットをコミットしないように設定する。
- [ ] **SEC-035:** 静的解析（SAST）と動的解析（DAST）の違いを説明できる。
- [ ] **SEC-036:** 脅威モデリングの基本的な考え方を説明できる。
