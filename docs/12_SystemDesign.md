# 12. システム設計

---
## 12.1. 可用性と信頼性
- [ ] **SD-001:** 可用性と信頼性の違いを説明できる。
- [ ] **SD-002:** SPOF（単一障害点）とは何かを説明できる。
- [ ] **SD-003:** 冗長化（Redundancy）の基本的な考え方を説明できる。
- [ ] **SD-004:** アクティブ/スタンバイ構成とアクティブ/アクティブ構成の違いを説明できる。
- [ ] **SD-005:** フェイルオーバーとフォールバックの違いを説明できる。
- [ ] **SD-006:** ヘルスチェックの役割を説明できる。
- [ ] **SD-007:** SLA 99.9%が年間の停止時間で何分に相当するかを計算できる。
- [ ] **SD-008:** RTO（目標復旧時間）とRPO（目標復旧時点）の違いを説明できる。

---
## 12.2. スケーラビリティ
- [ ] **SD-009:** スケールアップとスケールアウトの違いを説明できる。
- [ ] **SD-010:** ステートレスなアプリケーションがスケールアウトしやすい理由を説明できる。
- [ ] **SD-011:** ロードバランサー（LB）の基本的な役割を説明できる。
- [ ] **SD-012:** LBの代表的なアルゴリズム（ラウンドロビン、リーストコネクション）を説明できる。
- [ ] **SD-013:** オートスケーリングの仕組みを説明できる。
- [ ] **SD-014:** DBのリードレプリカの役割を説明できる。
- [ ] **SD-015:** DBのシャーディングの基本的な考え方を説明できる。

---
## 12.3. パフォーマンスとキャッシュ
- [ ] **SD-016:** CDN（コンテンツデリバリーネットワーク）の役割とメリットを説明できる。
- [ ] **SD-017:** ブラウザキャッシュの仕組み（`Cache-Control`ヘッダーなど）を説明できる。
- [ ] **SD-018:** アプリケーションレベルキャッシュ（インメモリキャッシュ）の使いどころを説明できる。
- [ ] **SD-019:** RedisやMemcachedなどの分散キャッシュのユースケースを説明できる。
- [ ] **SD-020:** キャッシュ戦略（ライトスルー、ライトバック、リードスルー）の違いを説明できる。
- [ ] **SD-021:** キャッシュの無効化（Cache Invalidation）の難しさを説明できる。
- [ ] **SD-022:** Thundering Herd Problem（キャッシュのスタンピード）とその対策を説明できる。

---
## 12.4. データとストレージ
- [ ] **SD-023:** CAP定理（一貫性、可用性、分断耐性）の概要を説明できる。
- [ ] **SD-024:** 結果整合性（Eventual Consistency）の概念を説明できる。
- [ ] **SD-025:** RDBとNoSQLの使い分けを説明できる。
- [ ] **SD-026:** オブジェクトストレージ（S3など）のユースケースを説明できる。
- [ ] **SD-027:** データウェアハウス（DWH）とデータレイクの違いを説明できる。

---
## 12.5. 通信と連携
- [ ] **SD-028:** 同期通信と非同期通信の使い分けを説明できる。
- [ ] **SD-029:** メッセージキュー（MQ）を使った非同期連携のメリットを説明できる。
- [ ] **SD-030:** Pub/Subモデルを説明できる。
- [ ] **SD-031:** APIゲートウェイの役割を説明できる。
- [ ] **SD-032:** サービスメッシュの役割を説明できる。
- [ ] **SD-033:** gRPCとRESTの違いを説明できる。
- [ ] **SD-034:** Webhookの仕組みを説明できる。
- [ ] **SD-035:** サーキットブレーカーパターンの役割を説明できる。
- [ ] **SD-036:** Idempotent Receiver（べき等な受信者）パターンの重要性を説明できる。
- [ ] **SD-037:** DNSの基本的な役割（名前解決）を説明できる。
- [ ] **SD-038:** CDNがどのようにDNSを利用しているか説明できる。
