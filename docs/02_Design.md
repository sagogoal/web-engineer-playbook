# 02. 基本設計

## 2.1. 図による表現
- [ ] **DGN-001:** Mermaid記法を使い、シーケンス図を作成できる。
  <details>
  <summary>手を動かす</summary>
  - 「ユーザーがログインボタンを押し、APIサーバーがDBを検証して、トークンを返す」という流れをMermaidのシーケンス図として記述する。
  </details>
- [ ] **DGN-002:** Mermaid記法を使い、ER図を作成できる。
  <details>
  <summary>手を動かす</summary>
  - 「1人のユーザーは複数の投稿を持つ（1対多）」という関係を、`users`と`posts`テーブルのER図としてMermaidで記述する。
  </details>
- [ ] **DGN-003:** Mermaid記法を使い、簡単なクラス図を作成できる。
  <details>
  <summary>手を動かす</summary>
  - `User`クラスが`name`プロパティと`getName()`メソッドを持つ、というクラス図をMermaidで記述する。
  </details>
- [ ] **DGN-004:** Mermaid記法を使い、簡単なフローチャートを作成できる。
- [ ] **DGN-005:** C4モデルの4つのレベル（コンテキスト、コンテナ、コンポーネント、コード）を説明できる。
- [ ] **DGN-006:** PlantUMLやMermaidなどのテキストベースの作図ツールを使うメリットを説明できる。
