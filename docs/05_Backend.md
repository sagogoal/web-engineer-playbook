## 5.3. 非同期処理・バッチ
- [ ] **BE-024:** 同期処理と非同期処理の使い分けを説明できる。
- [ ] **BE-025:** メッセージキュー（MQ）の役割を、流量制御と疎結合化の観点から説明できる。
- [ ] **BE-026:** MQを使い、ProducerとConsumerを作成してメッセージを送受信する。
  <details>
  <summary>手を動かす</summary>
  - 任意のMQ（RabbitMQ, SQSなど）を使い、「ユーザー登録時にメールを送信する」というシナリオで、API側（Producer）がメッセージをキューに送信し、別プロセス（Consumer）がそれを受信してメール送信処理（のログ出力）を行うサンプルを作成する。
  </details>
- [ ] **BE-027:** 멱等性（べきとうせい）とは何かを説明できる。

- [ ] **BE-029:** Cron形式のスケジュール設定を読める・書ける。
- [ ] **BE-030:** バッチ処理（ジョブ）の基本的な設計（入力、処理、出力）を説明できる。
