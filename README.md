# Webエンジニア実務チェックリスト

AI時代でも長期的に価値を出し続けられるWebエンジニアになるための、実務ベースの学習ロードマップ。

## コンセプト

一般的な技術一覧ではなく、**実務で遭遇するタスクを細分化したチェックリスト**です。
「実務で何を考え、何を確認し、何を実装するか」を体系化することを目的としています。

これは、パイロットや外科医が使うチェックリストのように、実務での抜け漏れを防ぎ、思考プロセスをサポートするためのものです。

## 対象レベル

- ジュニア〜ミドルレベルのWebエンジニア
- 実務経験3〜5年程度まで

## 進め方

各カテゴリのMarkdownファイルに、実務タスクに基づいたチェック項目が記載されています。

1.  興味のあるカテゴリ、もしくは現在業務で関連の深いカテゴリのファイルを開きます。
2.  各チェック項目の`ゴール`を達成することを目標とします。
3.  `完了条件`に従って学習を進め、チェックボックスを埋めていきます。
    -   Notionに300〜500文字でまとめる
    -   Ankiカードを3〜5枚作る
    -   サンプルコードを書く
    -   「実務ではいつ使うか」を1文で書く
4.  `実務での思考プロセス`は、タスクに取り組む際の思考のフレームワークとして活用してください。

## 学習計画のモデルケース

このチェックリストは合計1000項目以上あり、非常に広範囲にわたります。全てを一度にやろうとせず、継続的に学習を進めることが重要です。以下にいくつかのモデルケースを提案します。

### ペース配分

-   **目標期間:** 約1年
-   **ペース:** 1日3項目（約1.5時間）
-   **継続:** 週5日学習すると、 `3項目 * 5日 * 52週 = 780項目` となり、約1年強で一通り完了できる計算です。

もちろん、これはあくまで目安です。自分のペースに合わせて、無理なく継続できる計画を立ててください。

### 学習の進め方

#### 1. 水平型: まずは全体を広く浅く
各カテゴリの最初の10〜20項目（基礎的な部分）を、カテゴリ01から順番に一通り学習します。
これにより、Web開発の全体像を素早く把握することができます。まずは森を見てから、個々の木を詳しく見ていくスタイルです。

#### 2. 垂直型: 特定の分野を深く掘り下げる
「今の業務でバックエンド開発が中心だから、まずは `05_Backend.md` と `03_Database.md` を完璧にしよう」というように、自分の興味や現在の業務に直結する分野を深く掘り下げるスタイルです。
専門性を素早く高めることができます。

#### 3. T字型: 専門を持ちつつ、周辺も理解する（推奨）
「フロントエンドエンジニア」であれば、まず `06_Frontend.md` を深く学習して専門の縦棒を伸ばします。その後、関連の深い `02_Design.md`, `04_API.md`, `07_Test.md` などを広く学習し、知識の横棒を広げていきます。
専門性を持ちつつ、他の領域のエンジニアとも円滑にコミュニケーションが取れる、バランスの取れたスキルセットを目指すスタイルです。

どの進め方が最適かは、あなたの現在のスキルレベルやキャリアプランによって異なります。
自分に合った計画を立て、`artifacts` ディレクトリに学習の証を記録していきましょう。
