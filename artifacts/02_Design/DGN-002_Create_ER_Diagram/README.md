# DGN-002: Mermaid記法を使い、ER図を作成できる

## 学んだこと (300〜500字)
### ER図とは
ER図（Entity-Relationship Diagram）はデータベースの設計を表現するのに使用されます。エンティティ、その属性、およびエンティティ間の関係を示します。
エンティティとして、項目名、型と制約（PK、FK）を定義し、その関係を1対1や1対多で表現する。
