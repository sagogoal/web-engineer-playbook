# DGN-001: Mermaid記法を使い、シーケンス図を作成できる

## 学んだこと (300〜500字)
### Mermaid記法とは？
Mermaid（マーメイド）は、テキストベースの記法で様々な図表（フローチャート、シーケンス図、ER図など）を生成できるJavaScriptライブラリ
### Mermaid記法の基礎
- [概要](https://help.docbase.io/posts/3719897)
- [公式ドキュメント](https://mermaid.js.org/intro/)
- シーケンス図は、sequenceDiagramから開始する
  ┌──────┬──────────────────┬──────────────┐
  │ 記法 │ 意味             │ 線のスタイル │
  ├──────┼──────────────────┼──────────────┤
  │ ->   │ 実線（矢印なし） │ ───          │
  │ -->  │ 破線（矢印なし） │ ‑‑‑          │
  │ ->>  │ 実線（矢印あり） │ ───>         │
  │ -->> │ 破線（矢印あり） │ ‑‑‑>         │
  │ -x   │ 実線（終端が x） │ ───x         │
  │ --x  │ 破線（終端が x） │ ‑‑‑x         │
  └──────┴──────────────────┴──────────────┘
- activate/deactivateで処理期間を可視化できる

### VSCodeでマーメイド記法を可視化する方法
- Markdown Preview Mermaid Support という拡張を入れると、Mdファイルのプレビューを表示すると、Mermaidも変換される
- Mermaid Markdown Syntax Highlighting これで文法もハイライトしてくれる

### シーケンス図とは
処理の時系列を図で表現する。詳細設計レベルの処理がわかる図

## 実務利用シーン (1文)
認識合わせを行いたい処理の詳細設計をする。設計意図をドキュメントに残したい場合に利用できそう。
